    Vue d'ensemble : glissez dans le vide pour tourner, molette ou pincement pour zoomer vers le curseur, clic droit pour déplacer la vue, double-clic au sol pour s'y rendre. Cliquez un élément (kit ou mobilier) : glissez-le pour le déplacer, tournez-le avec l'anneau autour (Maj = par 15°) ; Q / E aussi. « Déplacer : une pièce » (ou double-clic) pour bouger une pièce seule. Suppr : retirer l'élément. F : plein écran ; Échap pour désélectionner.

    Personnage : un petit personnage se promène dans la salle, vu de derrière. ↑ / ↓ (ou Z / S, W / S) pour avancer ou reculer ; ← / → (ou Q / D, A / D) pour tourner (Maj pour courir). Glissez pour tourner la caméra autour de lui, molette pour l'éloigner ou le rapprocher, cliquez au sol pour qu'il y aille. Les éléments se sélectionnent et se déplacent comme d'habitude. F : plein écran. Échap pour quitter.

    Visite : vous êtes dans la salle, à hauteur d'yeux. Glissez pour regarder autour de vous ; W A S D ou les flèches pour marcher (Maj pour aller plus vite) ; cliquez au sol pour y aller ; la molette fait avancer ou reculer. Les éléments et le mobilier se déplacent et se tournent (anneau) comme en vue d'ensemble. F : plein écran, plus immersif. Échap pour quitter.

    Le principe

    Une tournée européenne

    Google Cloud emmène AI Advantage dans plus de 30 organisations en Europe en 2026 et nous propose d'accueillir une étape.

    Ils viennent chez nous

    Google apporte les démos, la logistique, le contenu et ses intervenants. Ils s'installent la veille et démontent juste après l'événement.

    Un programme fait sur mesure

    Nous construisons l'agenda ensemble, autour de nos priorités. C'est un événement privé, réservé à SNCF.

    Le but

    Embarquer largement les équipes, valoriser ce qui existe déjà et repérer concrètement ce qui peut accélérer nos cas d'usage.

    Document de travail, contenu indicatif. Basé sur la présentation « AI Advantage for SNCF » de Google Cloud et la synthèse interne.
